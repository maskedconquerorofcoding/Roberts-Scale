When grading overall changes in a mobile UI update, the 10 most critical factors to evaluate are usability, visual consistency, and performance:
Core Task Efficiency
Evaluate whether core actions (e.g., checking out, signing up, searching) take fewer steps or less time. Updates should reduce cognitive load, not add unnecessary clicks to complete primary tasks.
UI Standards & Styling
Check if the updated screens adhere to the platform's native design guidelines (e.g., Apple Human Interface Guidelines or Google Material Design). Typography, padding, and iconography should feel uniform across the entire app.
App Navigation & Layout
Assess the intuitiveness of the new navigation. Look for easily accessible primary tabs, clear "back" mechanisms, and whether the new layout buries essential features or declutters the interface effectively.
Content Layout & Text Readability
Grade how well the update prioritises content. Important text, primary buttons (CTAs), and alerts should immediately draw the eye, while secondary information takes a backseat. Text contrast and sizing should also meet WCAG Accessibility Guidelines.
Button & Element Feedback
Ensure the UI responds instantly to user input. Every tappable element—buttons, toggles, and links—should have distinct visual states (e.g., hover, pressed, and loading) to provide immediate tactile feedback.
Error Messages & Validation
A great UI update prevents user errors before they happen (e.g., inline form validation) and displays clear, actionable error messages if something goes wrong.
Loading Screens & Speed
Evaluate how the app handles delays. Smooth transitions, skeleton screens, and subtle micro-animations make the app feel faster and more polished, even when content is still fetching in the background.
Accessibility & Mode Settings
Assess whether the new UI accommodates diverse user needs. Support for Dynamic Type, VoiceOver/TalkBack, and native Dark/Light mode switching are mandatory standards for modern mobile grading.
Screen Reachability & Gestures
On modern, large-screen smartphones, primary navigation and critical action buttons should comfortably sit within the "thumb zone" (the lower half of the screen) to ensure easy one-handed reachability.
Visual Branding & Appearance
Ultimately, the UI update should reflect the current brand identity while feeling modern. The aesthetic should align with current industry standards without sacrificing functionality for the sake of looking trendy. 

This document defines a 10‑category, 20‑points‑each evaluation framework for grading mobile OS updates. The total possible score is 200, which you convert to a percentage for public presentation.
The grading method is called a Roberts Scale.
